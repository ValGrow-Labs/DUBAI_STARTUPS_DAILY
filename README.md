# Dubai Startups Daily (DSD)
### *Startup, Business & Technology News from Dubai & the UAE*

A high-fidelity editorial publication featuring dual-theme support (**Light Ivory & Deep Navy** and **Midnight Obsidian Luxe & Gold**).

---

## 🌟 Themes & Visual Identity

### 1. Dual-Theme Engine (Light & Dark)
* **One-Click Theme Toggle**: Located in the masthead navigation next to the search button (Sun ☀️ / Moon 🌙).
* **Automatic Persistence**: User preference is stored in `localStorage` (`dsd_theme`) and syncs seamlessly with OS preferences.
* **Smooth CSS Transitions**: 250ms transition curves across surface colors, text luminance, and borders.

### 2. Palette Specifications

| Surface / Token | Light Mode (Warm Ivory) | Dark Mode (Midnight Navy) |
| :--- | :--- | :--- |
| **Canvas Background** | `#FAF9F5` (Warm Editorial Ivory) | `#060C14` (Deep Midnight Obsidian) |
| **Primary Navy** | `#0B1726` | `#0A1320` / `#0E1B2C` (Elevated cards) |
| **Champagne Gold** | `#D4AF37` | `#D4AF37` / `#F5E6BE` |
| **Primary Text** | `#0B1726` (Deep Navy) | `#F1F5F9` (Crisp Slate White) |
| **Secondary Text** | `#525252` | `#94A3B8` / `#CBD5E1` |
| **Subtle Dividers** | `#E5E7EB` | `rgba(255, 255, 255, 0.1)` |
